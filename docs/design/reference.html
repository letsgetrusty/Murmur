Idle isn't shown — the pill fades to fully transparent between actions, so it never sits on screen doing nothing. Chosen direction 1A (waveform + ring): the single color-coded dot becomes a state-specific indicator (waveform / spinner / speaker / download / check / warning) in accent, on the near-black glass capsule, so each state reads at a glance without relying on the label.

Layout mirrors SuperWhisper; palette, copy, and the on-device stance are Murmur's. New vs today: a dedicated Home — the rest reorganizes existing Settings into SuperWhisper's clearer sidebar + card grouping. Hotkeys are rebound in one place (Shortcuts); Dictation and Read-aloud just reference them.
